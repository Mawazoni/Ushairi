# Ushairi

🚧 **Work in progress** 🚧

## Description
This repository contains research materials, data, and scripts for the acoustic analysis of Swahili poetry (*ushairi*). 

Specifically, it includes Python scripts utilizing [Parselmouth](https://parselmouth.readthedocs.io/) to interface with Praat for advanced audio processing and phonetic analysis.
